# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.1.0] - 2025-12-30

**Approved Release** - [doi:10.5066/P144K2NA](https://doi.org/10.5066/P144K2NA)

### Added
Incorporated optional module for variable diffusivity into core code.
Added several tools such as `Ash3d_ASCII_DepThin` which generates a plot of deposit
thickness vs distance, and `Ash3d_NetCDF_GenCTR` which can recreate an Ash3d
control file from a netcdf output file.

## [1.0.0] - 2025-01-08

**Approved Release** - [doi:10.5066/P1SJWAKZ](https://doi.org/10.5066/P1SJWAKZ)

This version is the official public release of Ash3d and the start of
semantic versioning.
